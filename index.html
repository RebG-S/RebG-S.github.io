Real-Time Network Telemetry

[Cisco / Python / InfluxDB / Grafana]

Developed an end-to-end network telemetry monitoring system to track live bandwidth utilization (RX/TX) on specific switch ports, bridging legacy hardware with modern time-series visualization.

Technical Highlights:

  • Data Collection: Built an async Python worker using SNMP v2c to efficiently poll switch interface metrics.
  • Data Storage: Configured InfluxDB to securely ingest, structure, and store high-frequency network metrics.
  • Visualization: Designed an enterprise-ready Grafana dashboard with real-time gauges, historical trends, and automatic unit conversions.
