Port Security Automation

Repository
[Cisco SF-300 / Python]

Technical Highlights:

MikroTik Network Segmentation & Firewall

[RouterOS / VLAN / Layer 3 Firewall]

A hands-on network segmentation lab built with MikroTik RouterOS and a Cisco SF300 managed switch. The setup uses separate VLANs for main and lab environments, with dedicated DHCP services, Inter-VLAN routing, firewall isolation, and NAT for internet connectivity.

Technical Highlights:

  • VLAN Segmentation: Configured VLAN 10 (192.168.10.0/24) and VLAN 20 (192.168.20.0/24) on MikroTik RouterOS to separate network environments.
  • VLAN Trunking: Configured the Cisco SF300 uplink as a trunk carrying tagged VLAN 10 and VLAN 20 traffic from the MikroTik.
  • Inter-VLAN Routing: Configured dedicated VLAN interfaces and gateways on MikroTik to enable Layer 3 communication between the segmented networks.
  • DHCP: Configured separate DHCP services for each VLAN to automatically assign addresses to connected devices.
  • Firewall Isolation: Implemented Layer 3 firewall filtering to prevent traffic from the lab VLAN from reaching the main network.
  • NAT: Configured source NAT (masquerade) to provide internet access to the segmented VLANs.
  • Traffic Monitoring: Used MikroTik's built-in graphing tools to monitor traffic across the VLAN interfaces.

Legacy Router Security Bot

Repository
[Linksys E900 / Python / Telegram API]

Designed and deployed a lightweight Telegram-based network management bot for a legacy Linksys E900 router, providing remote device monitoring and MAC filtering despite the router's lack of SSH-based management, overcoming stock firmware constraints without flashing custom ROMs.

Technical Highlights:

  • HTTP Automation: Automated authenticated HTTP GET/POST requests to interact with the router's web management interface.
  • DHCP Monitoring: Parsed the router's DHCP client table to retrieve connected device names, IP addresses, MAC addresses, and connection types.
  • MAC Filtering: Implemented remote device blocking and bulk unblocking by programmatically updating the router's wireless MAC filter configuration.
  • Telegram Interface: Built an interactive Telegram bot with inline controls for monitoring connected devices and blocking selected wireless clients.

Network Telemetry & Dashboard

Repository
[Cisco SF-300 / Python / InfluxDB / Grafana]

A personal networking project exploring SNMP-based telemetry by monitoring TX/RX traffic from a home Wi-Fi router connected to a Cisco SF300 switch.

Technical Highlights:

  • SNMP Collection: Developed an asynchronous Python worker to periodically poll interface statistics from the Cisco SF300 via SNMP v2c.
  • Data Processing: Calculated TX/RX bandwidth from interface counter changes between polling intervals.
  • Time-Series Storage: Stored collected metrics in InfluxDB for historical analysis.
  • Visualization: Built a Grafana dashboard with real-time gauges and historical traffic graphs.
